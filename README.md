> A curated list of resources for Svelte, SvelteKit framework, fine-grained reactivity engines, Runes, UI component libraries, state management, and developer tooling.

Svelte is a radical, compiler-driven web framework that shifts work from the runtime browser to the build step. By converting components into tiny, highly optimized imperative JavaScript code during compilation, Svelte eliminates the overhead of a virtual DOM, delivering ultra-fast initial page loads and minimal memory footprints. This list is intended for frontend engineers, full-stack developers, Svelte software architects, and UI engineering leads.

## Frameworks & Server-Side Rendering

Application frameworks, static site generators, and edge-rendering engines built on Svelte.

- [SvelteKit](https://github.com/sveltejs/kit) — Official full-stack application framework for Svelte featuring file-based routing, server-rendered components, API endpoints, and adapter-based deployment.
- [Astro Svelte Integration](https://github.com/withastro/astro) — Island architecture framework enabling zero-JavaScript static rendering with selective hydration for Svelte components.
- [Elder.js](https://github.com/elderjs/elderjs) — Opinionated Svelte framework designed for building massive, high-performance SEO-focused websites and static builds.

## State Management & Data Fetching

Reactive state primitives, persistent stores, asynchronous caching engines, and GraphQL integration.

- [TanStack Query (Svelte Query)](https://github.com/TanStack/query) — Powerful asynchronous state management engine for fetching, caching, and updating server state in Svelte apps.
- [Svelte Stores Core](https://github.com/sveltejs/svelte) — Built-in reactive store system providing writable, readable, and derived data abstractions across component trees.
- [Houdini GraphQL](https://github.com/HoudiniGraphql/houdini) — Declarative, compiler-enhanced GraphQL client for SvelteKit and standalone Svelte applications.
- [Lucia](https://github.com/lucia-auth/lucia) — Flexible, framework-agnostic session-based authentication engine optimized for SvelteKit web applications.

## UI Component Libraries & Styling

Design systems, headless UI component primitives, icon packages, and animation engines for Svelte.

- [Bits UI](https://github.com/huntabyte/bits-ui) — Unstyled, accessible component primitives designed for crafting custom design systems in Svelte.
- [shadcn-svelte](https://github.com/huntabyte/shadcn-svelte) — Port of shadcn/ui for Svelte powered by Bits UI and Tailwind CSS for reusable component compositions.
- [Svelte Material UI (SMUI)](https://github.com/hperrin/svelte-material-ui) — Collection of accessible Material Design components implemented as native Svelte components.
- [Flowbite Svelte](https://github.com/themesberg/flowbite-svelte) — Open-source UI component library constructed with Svelte components and styled using Tailwind CSS.
- [Svelte Motion](https://github.com/sveltemotion/sveltemotion) — Animation library for Svelte applications ported from Framer Motion.

## Routing & Navigation

Routing toolkits, URL state management engines, and schema-based form builders.

### Full-Stack Routers

- [svelte-routing](https://github.com/EmilTholin/svelte-routing) — Declarative SPA routing library for Svelte using familiar Route and Link components.
- [tinro](https://github.com/AlexxNB/tinro) — Zero-dependency, lightweight, hash and HTML5 history mode router for Svelte.

### Form Management & Validation

- [Superforms](https://github.com/cscape/sveltekit-superforms) — Comprehensive server and client validation library tailored for SvelteKit forms using Zod or Valibot schemas.
- [Felte](https://github.com/pablo-abc/felte) — Extensible form management library designed for Svelte with built-in validation engine hooks.

## Developer Tooling & Integrations

Build utilities, IDE language servers, preprocessors, and testing frameworks.

- [Svelte Language Tools](https://github.com/sveltejs/language-tools) — Official Language Server Protocol (LSP) implementation providing Intellisense, diagnostics, and type-checking.
- [svelte-preprocess](https://github.com/sveltejs/svelte-preprocess) — Official preprocessor supporting TypeScript, PostCSS, SCSS, Less, Stylus, and Pug inside Svelte files.
- [vite-plugin-svelte](https://github.com/sveltejs/vite-plugin-svelte) — Official Vite plugin supplying fast compilation and hot module replacement (HMR) for Svelte components.
- [Testing Library Svelte](https://github.com/testing-library/svelte-testing-library) — Lightweight utility for testing Svelte components encouraging user-centric assertion patterns.
